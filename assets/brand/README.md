# Proper Emails loop-mark identity

The owner approved logo direction **B — Loop mark** on 20 October 2026.

- `mark.svg`: dark mark with lime counter, for light backgrounds.
- `mark-light.svg`: cream mark with lime counter, for dark backgrounds.
- `mark-mono.svg`: monochrome mark.
- `logo.svg` / `logo-light.svg`: portable stacked wordmark lockups, with PNG copies.
- `app-icon.svg` and PNG sizes 16, 32, 48, 180, 192 and 512: browser/mobile icon artwork.
- Root `favicon.svg` and `favicon.ico`: modern SVG and multi-size ICO fallbacks.

The website's wordmark uses its existing Manrope font. Exported SVG lockups use Arial Black with Arial/sans-serif fallbacks; the mark itself is pure vector paths and does not depend on a font. Do not stretch or rotate the mark. Preserve clear space and contrast. The compact browser icon uses the approved loop silhouette with a clear dark counter for small-size legibility.

Logo concepts were explored with the built-in image-generation tool. The selected B silhouette was then reconstructed as editable SVG for sharp rendering and favicon export. The source exploration board is an approval artifact, not the production logo file.
